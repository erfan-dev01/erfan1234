واژه‌نامه

واژگان کلیدی Git و GitHub

Repository

مخزن؛ پوشهٔ پروژه همراه با تمام تاریخچه (پوشهٔ .git).

Commit

یک نقطهٔ ذخیره با شناسهٔ یکتا (hash)، نویسنده، زمان و پیام.

Branch

شاخه؛ خط توسعهٔ مستقل. شاخهٔ اصلی: main.

HEAD

اشاره‌گر به جایی که همین حالا روی آن هستید.

Remote / origin

نسخهٔ آنلاین مخزن؛ origin نام پیش‌فرض آن است.

Clone / Fork

Clone: کپی روی کامپیوتر. Fork: کپی شخصی روی حساب GitHub.

Merge

ادغام تغییرات یک شاخه در شاخهٔ دیگر.

Pull Request

درخواست بازبینی و ادغام یک شاخه در GitHub.

Staging Area

جایگاه موقت فایل‌هایی که قرار است وارد commit بعدی شوند.

Tag / Release

برچسب یک نسخهٔ پایدار مثل v1.0.0 و صفحهٔ انتشار آن.

مرور سریع: هر واژه را با یک جملهٔ خودتان توضیح بدهید؛ اگر نشد، همان اسلاید را دوباره ببینید.

بخش ۲ ⏱ ۱۰ دقیقه
برگشت به عقب: restore، reset، revert




↩️
git restore file
لغو تغییرات ذخیره‌نشده در فایل. بی‌خطر نیست: تغییرات برنمی‌گردند.


📤
git restore --staged
برگرداندن فایل از Staging به حالت عادی.


⏮️
git reset --soft HEAD~1
حذف آخرین commit و حفظ تغییرات. فقط برای commitهای Push نشده.


🛟
git revert HEAD
ساخت commit جدید که اثر قبلی را خنثی می‌کند؛ امن برای کار تیمی.




قاعده: روی چیزی که Push شده، از revert استفاده کنید نه reset. git reflog آخرین نجات‌دهنده است.


تمرین: یک فایل را خراب کنید و با restore برگردانید؛ سپس یک commit اشتباه بزنید و با revert خنثی کنید.

بخش ۳
Remote: ارتباط با GitHub


$ git remote -v
$ git fetch origin
$ git pull --rebase origin main
$ git push origin feature/login
$ git remote set-url origin git@github.com:USER/repo.git
$ git remote add upstream https://github.com/ORIGINAL/repo.git
$ git fetch upstream
fetch در برابر pull
fetch فقط دانلود می‌کند و چیزی را تغییر نمی‌دهد؛ pull دانلود + ادغام است.
upstream
در Fork، آدرس مخزن اصلی؛ برای هم‌گام‌ماندن با آن.
set-url
تغییر آدرس origin، مثلاً از HTTPS به SSH.


قاعده: قبل از شروع کار git pull و بعد از commit، git push.

عیب‌یابی
خطاهای رایج و راه‌حل


🚫
not a git repository
داخل پوشهٔ مخزن نیستید: cd یا git init.
⛔
rejected (non-fast-forward)
ابتدا git pull بزنید، تعارض را حل و دوباره Push کنید.
🔑
Permission denied (publickey)
کلید SSH اضافه نشده؛ با ssh -T git@github.com تست کنید.
🔒
Authentication failed
رمز حساب قبول نیست؛ از Token یا Credential Manager استفاده کنید.
🧭
detached HEAD
روی یک commit قدیمی هستید: git switch main.
🪪
Please tell me who you are
user.name و user.email را تنظیم کنید.


عادت حرفه‌ای: هر خطا را کامل بخوانید؛ Git معمولاً راه‌حل را همان‌جا می‌نویسد. گیج شدید: git status.
